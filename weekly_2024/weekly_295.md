1. [icefox](https://github.com/xiaopanglian/icefox): Typecho 主题，类似微信朋友圈的设计风格
2. [BetterGI](https://github.com/babalae/better-genshin-impact): 原神自动化工具，支持自动拾取、剧情、邀约等
3. [libcimbar](https://github.com/sz3/cimbar): 用二维码传输文件的工具
4. [Tetris-SQL](https://github.com/nuno-faria/tetris-sql): 用 SQL 写的俄罗斯方块
5. [Pastebin-worker](https://github.com/SharzyL/pastebin-worker): 基于 Cloudflare worker 的在线文件存储平台
6. [AutoCursorLock](https://github.com/James-LG/AutoCursorLock): 轻量级自动光标锁定工具，支持 Windows 平台
7. [Windows Update Disabler](https://github.com/tsgrgo/windows-update-disabler): 永久禁用 Windows 自动更新的脚本工具
8. [ComputerLock](https://github.com/JiuLing-zhang/ComputerLock): 开源 Windows 锁屏工具
9. [Memospot](https://github.com/memospot/memospot): 开源 Memos 独立桌面版本，支持多平台
10. [BiglyBT](https://github.com/BiglySoftware/BiglyBT-Android): 无广告开源种子下载客户端，支持 Android 平台
