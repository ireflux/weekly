# 实用工具

1. [Photoview](https://github.com/photoview/photoview): 开源自托管个人服务器照片库，支持照片和视频的自动索引
2. [DockDoor](https://dockdoor.net/): 开源 macOS Dock 预览和窗口管理切换工具，支持窗口预览和类似 Windows 的快捷键切换窗口功能
3. [bilibili-manga-downloader](https://github.com/lanyeeee/bilibili-manga-downloader): 哔哩哔哩漫画下载器，支持多线程下载和图形界面
4. [Ghost Downloader](https://github.com/XiaoYouChR/Ghost-Downloader-3): 基于 PySide6 的新一代多线程下载器，支持多线程下载、断点续传、下载记录和文件校验功能
5. [web-realesrgan](https://github.com/xororz/web-realesrgan): 浏览器本地图像超分辨率工具，支持 WebGL 和 WebGPU 加速
6. [多轨快传](https://github.com/weixiansen574/HybridFileXfer): 同时使用 USB 和 WIFI 等多张网卡传输文件到电脑的软件
7. [LinkAndroid](https://github.com/modstart-lib/linkandroid): 免费开源全能手机连接助手，支持 Android 和电脑的连接
8. [aural-player](https://github.com/kartik-venugopal/aural-player): 开源 macOS 音乐播放器，灵感来源于经典的 Winamp 播放器
9. [Music](https://github.com/MissingCore/Music): 开源 Nothing 风本地音乐播放器，支持 Android 7 及以上系统
10. [GeoPort](https://github.com/davesc63/GeoPort): 开源易用的 iOS 虚拟定位工具，支持 iOS 17 和 iOS 18 系统
11. [Real-Address-Generator](https://github.com/Adonis142857/Real-Address-Generator): 开源地址生成器，选择国家后自动生成地址
12. [ab-download-manager](https://github.com/amir1376/ab-download-manager): 开源免费下载管理工具，支持 Windows 和 Linux
13. [咩Display](https://github.com/zanjie1999/meDisplay): 将任何支持浏览器的设备作为 Mac 的副屏
