# 实用工具

1. [心绪日记](https://github.com/ZhuJHua/moodiary): 简洁易用开源跨平台日记应用，支持加粗、斜体、下划线等多种格式的文本编辑
2. [Markdown To Poster](https://github.com/gcui-art/markdown-to-image): 可以将 Markdown 渲染为漂亮的社交媒体图片的开源工具，支持模板扩展和自定义主题
3. [R3PLAYX](https://github.com/Sherlockouo/music): 高颜值第三方网易云播放器，支持网易云账号登录、MV 播放、歌词显示等功能
4. [Little File Explorer](https://github.com/martinmimigames/little-file-explorer): 极简轻量文件资源管理器，体积仅 40KB 左右
5. [冰社](https://github.com/bingqiu456/IceCore): 集成了各种好玩功能的 Xposed 模块，支持获取 VIP、去除广告等功能
6. [bilibili-backup](https://github.com/hzhilong/bilibili-backup): 一键对 B 站账号进行数据备份和还原的开源工具
7. [cat-osint](https://github.com/cat-bucket/cat-osint): Termux 工具指令，用于短信轰炸和邮箱爆破，可以一键命令快速启动
8. [CloudPaste](https://github.com/ling-drag0n/CloudPaste): 基于 Cloudflare Workers 的在线剪贴板和文件分享服务，支持 Markdown、密码保护等功能
9. [MultiWeChatManager](https://github.com/wfql1024/MultiWeChatManager): 微信多开管理器，用于管理多个微信账号的桌面应用程序
10. [Qscan](https://github.com/qi4L/qscan): 开源轻量化全方位内网扫描器，支持多种扫描模式和多线程扫描
11. [QrCodeScanner](https://github.com/1357310795/QrCodeScanner): 简易二维码/条形码扫描器，支持截图识别、摄像头识别等多种模式
12. [WindowResizer](https://github.com/zhongyang219/WindowResizer): Windows 窗口大小调整器，适用于无法调整大小的窗口
13. [Zeal](https://github.com/zealdocs/zeal): 开源简单的离线文档浏览器，支持从 Dash 下载数百种编程语言、框架和工具的文档
14. [Stapxs QQ Lite 2.0](https://github.com/Stapxs/Stapxs-QQ-Lite-2.0): 非官方的网页 QQ 客户端，支持自适应布局、消息处理、群管理等功能
15. [dmMiniPlayer](https://github.com/apades/dmMiniPlayer): 增强版弹幕画中画播放器，支持最新的画中画 API 功能
16. [copymanga-downloader](https://github.com/lanyeeee/copymanga-downloader): 拷贝漫画下载器，支持下载下架漫画
