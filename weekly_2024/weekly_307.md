# 实用工具

1. [Interview Coder](https://github.com/ibttf/interview-coder): 一款隐形桌面应用，专为技术面试准备的 AI 辅助工具，具有智能截图、AI 分析代码问题、实时代码调试等功能
2. [SmolChat-Android](https://github.com/shubham0204/SmolChat-Android): 在安卓设备上本地运行小型语言模型的应用，无需联网即可享受个性化对话体验
3. [Harmony-Music](https://github.com/anandnet/Harmony-Music): 跨平台的在线音乐播放软件，支持 Android，Linux 和 Windows
4. [docker-wechat](https://github.com/RICwang/docker-wechat): 在 Docker 里运行微信的项目，可以用于保存聊天记录或者无限多开
5. [Overmorrow](https://github.com/bmaroti9/Overmorrow): 开源极简多彩天气应用，支持多种天气服务提供商
6. [Twinkle Tray](https://github.com/xanderfrangos/twinkle-tray): 在系统托盘管理多台显示器的亮度的工具，支持 Windows
7. [Alger Music Player](https://github.com/algerkong/AlgerMusicPlayer): 高颜值第三方网易云音乐播放器，适配 Web 端、桌面端、Web 移动端
8. [AWAvenue 秋风广告规则](https://github.com/TG-Twilight/AWAvenue-Ads-Rule): 优秀的广告过滤规则，适用于 AdGuard Home、AdGuard、AdGuard DNS等
9. [EasyTransfer](https://github.com/WCY-dt/EasyTransfer): 免费开源的文件传输工具，支持大文件传输、拍照传输、纯文本传输
10. [Education Clock](https://github.com/Return-Log/Education-Clock): 开源实用班级信息看板，具有倒计时、桌面时钟、课程表等功能
11. [Easy Notes](https://github.com/Kin69/EasyNotes): 开源美观 Android 笔记应用，采用 Material You 设计
12. [Wave](https://github.com/wavetermdev/waveterm): 开源的跨平台终端工具，结合命令行界面与图形化组件
13. [Readest](https://github.com/chrox/readest): 开源强大现代化电子书阅读器，支持多种电子书格式
