# 实用工具

1. [ProjectM](https://github.com/projectM-visualizer/projectm): 开源的音乐可视化工具
2. [iPlay](https://github.com/ourfor/iPlayClient): 开源跨平台视频播放器
3. [Inpaint web](https://github.com/lxfater/inpaint-web): 免费开源的图像修复和无损放大工具
4. [Snap.Hutao](https://github.com/DGP-Studio/Snap.Hutao): 专为 Windows 平台设计的原神工具箱，提供多账号切换等功能
5. [Rectangle](https://github.com/rxhanson/Rectangle): macOS 上的窗口管理工具，通过键盘快捷键快速移动和调整窗口大小
6. [Shell](https://github.com/moudey/Shell): Windows 上下文菜单管理工具，扩展右键菜单功能，免费开源无广告
7. [MediaCrawler](https://github.com/NanmiCoder/MediaCrawler): 抓取社交媒体信息的网络爬虫工具，支持小红书、抖音等平台
8. [Crow Translate](https://github.com/crow-translate/crow-translate): 支持多翻译 API 的简单轻量级翻译软件
9. [DevHub](https://github.com/jaywcjlove/DevHub): 专为开发者设计的多功能离线工具集，支持 macOS
10. [Bili2text](https://github.com/lanbinshijie/bili2text): 将 Bilibili 视频转换为文本的工具
11. [Douyin](https://github.com/zyronon/douyin): 基于 Vue 的模仿抖音移动端短视频项目
12. [微信对话生成器](https://gitee.com/lifeixue/weixin-chat): 模拟微信聊天的工具，支持发送各种消息类型
