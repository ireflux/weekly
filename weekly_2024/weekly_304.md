# 实用工具

1. [Focalboard](https://github.com/mattermost-community/focalboard): 开源项目管理工具，作为 Trello、Notion 和 Asana 的自托管替代方案，支持个人桌面版和多用户服务器版，具备看板、任务管理等核心功能
2. [Little Big Mouse](https://github.com/mgth/LittleBigMouse): 开源多屏光标移动与显示对齐优化工具，专为多显示器用户设计
3. [Muffon](https://github.com/staniel359/muffon): 跨平台桌面音乐流媒体客户端，支持多个音乐平台
4. [Drawnix](https://github.com/plait-board/drawnix): 开源一体化白板工具，支持思维导图、流程图和自由绘图功能
5. [Dufs](https://github.com/sigoden/dufs): 功能强大开源轻量级文件服务器，支持静态文件服务、文件上传、搜索和访问控制等多种功能
6. [OSX](https://github.com/dockur/macos): 在 Docker 容器中运行 macOS 的项目
7. [AkelPad](https://github.com/ssrlive/akelpad): 开源轻量级 Windows 文本编辑器
8. [Simple Screen Recorder](https://github.com/lextrack/Simple-Screen-Recorder): 开源屏幕录制工具
9. [InputShare](http://github.com/BHznJNs/InputShare): 与 Android 设备无缝共享计算机的键盘、鼠标和剪贴板的软件
10. [GitHub Desktop](https://github.com/zetaloop/desktop): 开源 GitHub 第三方中文客户端
11. [BLEUnlock](https://github.com/ts1/BLEUnlock): 利用蓝牙设备解锁/锁定 MAC 设备的工具
12. [venera](https://github.com/venera-app/venera): 开源本地和网络漫画的阅读器
13. [XTCEasyRootPlus](https://github.com/OnesoftQwQ/XTCEasyRootPlus): 小天才电话手表一键 Root 程序
14. [misakaX](https://github.com/straight-tamago/misakaX): iOS/iPadOS 系统定制增强工具
15. [OpenInTerminal](https://github.com/Ji4n1ng/OpenInTerminal): 适用于 macOS 的 Finder 工具栏应用，快速在终端打开目录或文件
16. [文颜](https://github.com/caol64/wenyan): 开源 Markdown 文章排版美化工具
