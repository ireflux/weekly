3. [NoteGen](https://github.com/codexu/note-gen): 开源跨平台Markdown笔记应用，基于 Tauri + ChatGPT，帮助用户快速保存碎片化知识
4. [gah](https://github.com/marverix/gah): 无需管理员权限即可安装 GitHub 应用的便捷工具，支持 Linux 和 MacOS 系统
5. [Van Hub](https://github.com/Mereithhh/van-hub): 开源自托管的网站汇总平台，内嵌页面无需跳转
6. [Mangal](https://github.com/metafates/mangal): 功能强大的命令行漫画下载工具，内置多个漫画源
7. [ModernFlyouts](https://github.com/ModernFlyouts-Community/ModernFlyouts): 一组开源现代化的 Windows 浮出控件，基于 Fluent Design
8. [Changedetection](https://github.com/dgtlmoon/changedetection.io): 开源的网站监控工具，可通过多种方式触发通知
