4. [Modern Unix](https://github.com/johnalanwoods/maintained-modern-unix): 现代 Unix 命令替代集，提供现代化 Unix 命令替代品
5. [ChatCopilot](https://github.com/lw396/ChatCopilot): 获取微信聊天记录并支持实时存储到数据库的工具
6. [Seabird](https://github.com/getseabird/seabird): 原生跨平台 Kubernetes 桌面客户端，简化集群资源探索
7. [BCUninstaller](https://github.com/Klocman/Bulk-Crap-Uninstaller): 开源的软件卸载工具，支持检测程序和清理残留物等
8. [mTab](https://github.com/tsxcw/mtab): 开源新标签页工具，支持跨设备和跨浏览器同步
9. [SunEditor](http://suneditor.com/): 开源 Web 端 HTML 编辑器，轻量级且灵活
10. [wx-dump-4j](https://github.com/xuchengsheng/wx-dump-4j): Java 版微信聊天记录备份与管理工具，支持 Windows
11. [Tduck](https://github.com/TDuckCloud/tduck-front): 开源数据收集、问卷调查/表单系统
12. [AppRhyme](https://github.com/canxin121/app_rhyme): 免费开源跨平台音乐播放器，支持多平台
13. [MinaPlay](https://nepsyn.github.io/minaplay): 基于 RSS 订阅的追番/追剧个人媒体库
