# 实用工具

1. [nextplayer](https://github.com/anilbeesetti/nextplayer): 开源视频播放器，基于 Material You 设计
2. [KPlayer](https://github.com/bytelang/kplayer-go): 视频资源循环直播推流工具
3. [OCS 网课助手](https://github.com/ocsjs/ocsjs): 开源网课刷课脚本/软件，支持多平台和自动刷课功能
4. [text blind watermark](https://github.com/guofei9987/text_blind_watermark): 开源文本隐水印嵌入工具，使用频域技术嵌入信息，保护文本版权和来源
5. [video-subtitle-remover](https://github.com/YaoFANGUK/video-subtitle-remover): 基于 AI 技术的软件，能够无损分辨率去除视频中的硬字幕，并填充去除字幕后的区域
6. [oneAnime](https://github.com/Predidit/oneAnime): 使用 Flutter 开发的 Anime 第三方客户端，简洁无广告
7. [SyncClipboard](https://github.com/Jeric-X/SyncClipboard): 跨平台剪贴板同步方案，支持文字、图片和文件同步
8. [FreeAskInternet](https://github.com/nashsu/FreeAskInternet): 开源的 Perplexity AI 代替方案，本地运行的聊天机器人和答案生成工具
9. [游戏存档管理器](https://github.com/mcthesw/game-save-manager): 管理游戏存档文件的工具，支持描述、保存、删除、覆盖等操作
10. [Easy email](https://github.com/zalify/easy-email): 基于 MJML 的电子邮件编辑器，支持浏览器和 Node.js 环境
11. [Minesweeper-Desktop](https://github.com/cameron-goddard/Minesweeper-Desktop): macOS 桌面版扫雷游戏，提供经典的游戏体验
12. [AURORA](https://github.com/aurora-develop/aurora): 免费使用 ChatGPT 3.5 API 的项目，支持多平台一键部署
13. [DDColor](https://github.com/piddnad/DDColor): 开源的黑白图像上色模型，能够生成自然生动的彩色结果，支持多种图像格式输入
14. [Pot](https://github.com/pot-app/pot-desktop): 翻译工具，提供多种翻译方式和接入多款专业翻译引擎
15. [Uncle 小说](https://uncle-novel.github.io/uncle-novel-official-site): 开源全网小说下载器及阅读器，支持多种格式和功能
17. [AirBattery](https://github.com/lihaoyun6/AirBattery): Mac 端设备电量显示和管理工具，支持多种电量显示小组件
18. [Z2H字帖](https://paper.z2h.cn/): 在线字帖生成工具，支持自定义字帖，包括排版、描红样式和字体选择
