# 实用工具

1. [ChatLab]((https://github.com/hellodigua/ChatLab): 跨平台本地化聊天记录分析工具，支持 Discord 微信等导入并用 SQL 与 AI 进行关键词统计趋势洞察
2. [macUSB](https://github.com/Kruszoneq/macUSB): macOS 图形化工具，在现代 Mac 上拖拽创建旧款 Mac 可启动的 macOS/OS X USB 安装盘
3. [BentoPDF](https://github.com/alam00000/bentopdf): 自托管在线 PDF 工具箱，浏览器本地完成合并拆分压缩 OCR 等操作无需上传文件
4. [Quotio](https://github.com/nguyenphutrong/quotio): macOS 菜单栏 AI 配额管理工具，集中监控 Claude Gemini OpenAI 额度并自动切换账号代理
5. [AltSendme](https://github.com/tonyantony300/alt-sendme): 跨平台 P2P 文件传输工具，通过临时分享码直连无需注册即可发送任意大小文件
6. [GitHub Store](https://github.com/rainxchzed/Github-Store): Kotlin 跨平台应用，把 GitHub Releases 变成 Play Store 自动识别 APK EXE DMG 等并提供更新提醒
7. [DPanel](https://github.com/donknap/dpanel): 轻量化 Docker 可视化管理面板，支持容器镜像 Compose 一键脚本部署
