# 实用工具

1. [Checkmate](https://github.com/bluewave-labs/checkmate): 开源自托管工具，实时跟踪和监控服务器硬件、正常运行时间、响应时间和事件，并提供美观的可视化界面
2. [Pretty Snap](https://github.com/kangabru/pretty-snap): 开源屏幕截图美化工具，为截图添加美观的背景
3. [city-roads](https://github.com/anvaka/city-roads): 开源工具，可视化任意城市的所有道路，只需输入城市名称即可绘制
4. [Danmaku Anywhere](https://github.com/Mr-Quin/danmaku-anywhere): 开源浏览器插件，为任何视频网站添加弹幕功能
5. [Olib开放图书](https://github.com/shiyi-0x7f/o-lib): 免费开源 Zlibrary 书籍下载工具，免梯高速下载 Zlibrary 书籍
6. [gitdiagram](https://github.com/ahmedkhaleel2004/gitdiagram): 将任何 GitHub 代码库一键转换成互动式图表，让代码结构一目了然
7. [ZeroOmega](https://github.com/zero-peak/ZeroOmega): 开源的网络代理管理工具，可用于快速切换多个代理，同时支持浏览器三巨头
8. [arnis](https://github.com/louis-e/arnis): 基于 OpenStreetMap 的地理空间数据，通过 Rust 创建复杂而逼真的《我的世界》场景
9. [Nrfr](https://github.com/Ackites/Nrfr): 无需 Root，基于 Android 系统原生 API，实现解锁运营商限制、优化信号显示、突破区域限制等功能
10. [BeatPrints](https://github.com/TrueMyst/BeatPrints): 开源 Python 工具，帮助用户轻松创建 Pinterest 风格的音乐海报
11. [123pan_unlock](https://github.com/QingJ01/123pan_unlock): 专业的 123 云盘增强脚本，完美解锁会员功能、突破下载限制、去广告、支持自定义用户信息
12. [ArchiSteamFarm](https://github.com/JustArchiNET/ArchiSteamFarm): 一个旨在帮助用户同时管理多个 Steam 账户的开源工具，并通过模拟游戏运行自动获取 Steam 集换式卡牌
13. [browsr](https://github.com/juftin/browsr): 一个终端文件浏览器，提供友好的文本用户界面 TUI，支持浏览本地和远程文件系统
14. [MiceWine](https://github.com/KreitinnSoftware/MiceWine-Application): 一个致力于在 Android 智能手机上运行 Windows 应用程序和游戏的项目
15. [Darock-Bili](https://github.com/Darock-Studio/Darock-Bili/): 一个跨平台 watchOS 原生 B 站客户端，支持登录账号、个性化推荐、下载视频，对视频点赞、投币、收藏等功能
16. [Vectras VM](https://github.com/xoureldeen/Vectras-VM-Android): 一款基于 QEMU 的 Android 虚拟机应用，允许用户在 Android 设备上模拟运行多种操作系统
