# 实用工具

1. [ANI-RSS](https://github.com/wushuo894/ani-rss): 一个自动追番和动漫资源下载工具，支持通过蜜柑 RSS 等源自动订阅番剧更新并推送至下载器
2. [ai-goofish-monitor](https://github.com/dingyufei615/ai-goofish-monitor): 一个基于 Playwright 和 AI 的闲鱼商品实时监控工具，支持多任务并发监控和智能化分析
3. [SaveDesktop](https://github.com/vikdevelop/SaveDesktop): 一个适用于多种 Linux 桌面环境的一键备份与还原工具，支持个性化设置迁移
4. [LottieViewConvert](https://github.com/SwaggyMacro/LottieViewConvert): 一个跨平台动画转换工具，支持将 TGS、Discord 贴纸和 Lottie 文件批量转换为多种格式
5. [Hover Zoom+](https://github.com/extesy/hoverzoom): 一款浏览器扩展，支持鼠标悬停时自动放大网页缩略图或视频链接
6. [PdfItDown](https://github.com/AstraBert/PdfItDown): 一个将多种文件格式轻松转换为 PDF 的 Python 工具，支持 Markdown、Word、Excel、图片等
7. [Chroma](https://github.com/ubisoft/Chroma): 一款专为游戏开发设计的色盲检测工具，支持实时模拟三种主要色盲类型
