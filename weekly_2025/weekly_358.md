# 实用工具

1. [PiliPro](https://github.com/naaammme/pilipro): Android 第三方哔哩哔哩客户端，免登录可播放并自动本地保存弹幕评论同时支持画中画小窗播放
2. [HaKa Comic](https://github.com/raoxwup/haka_comic): 基于 Flutter 的跨平台哔咔漫画阅读器，界面清爽无广告支持分类浏览与 ID 分享
3. [Petrichor](https://github.com/kushalpandya/Petrichor): macOS 离线音乐播放器，支持 FLAC 等高解析音频与按艺术家专辑年份浏览
4. [OpenScreen](https://github.com/siddharthvaddem/openscreen): 跨平台屏幕录制工具，可窗口录制并实时添加缩放动画与背景模糊
5. [ScrollSnap](https://github.com/Brkgng/ScrollSnap): macOS 滚动长截屏拼接工具，本地完成网页或聊天记录全图捕获无需上传云端
6. [iDescriptor](https://github.com/iDescriptor/iDescriptor): 跨平台 iOS 设备管理工具，支持 USB 文件浏览照片导入及越狱设备访问与 AirPlay 镜像
7. [IReader](https://github.com/IReaderorg/IReader): 插件化跨平台小说阅读器，支持书库管理章节下载与桌面版 TTS 朗读
8. [NPatch](https://github.com/7723mod/NPatch): Android 免 Root Xposed 框架，通过注入文件让模块在未 ROOT 设备运行
9. [Notebook Navigator](http://github.com/johansan/notebook-navigator): Obsidian 双面板文件导航插件，支持多语言与自定义排序
10. [lstr](https://github.com/bgreenwell/lstr): Rust 极速目录树查看器，支持并行扫描与交互模式及 Git 状态显示
11. [Cyme](https://github.com/tuna-f1sh/cyme): 跨平台现代化 USB 设备列表工具，支持过滤与树状彩色输出可替代 lsusb
12. [any-distance-ios](https://github.com/Any-Distance/any-distance-ios): 2023 苹果设计奖获奖运动追踪应用，支持 HealthKit Garmin 等多数据源
