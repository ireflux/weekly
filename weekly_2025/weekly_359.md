# 实用工具

1. [Windows-Manage-Tool](https://github.com/Zhu-junwei/Windows-Manage-Tool): Windows 命令菜单式系统优化工具，可一键调整外观网络更新等深层设置
2. [BiliPai](https://github.com/jay3-yy/BiliPai): Jetpack Compose 打造的 Android 第三方 B 站客户端，支持扫码登录与动态配色高清播放
3. [Manga Translator](https://github.com/hgmzhn/manga-translator-ui): Windows 一键漫画翻译工具，支持日漫韩漫彩漫并内置 OpenAI Gemini 等五种翻译引擎
4. [OpenComic](https://github.com/ollm/OpenComic): 跨平台漫画阅读器，支持 CBZ PDF EPUB 等格式与 Webtoon 双页滚动多种阅读模式
5. [Chrome++](https://github.com/Bush2021/chrome_plus): DLL 劫持增强 Chrome 原生功能，支持双击关闭标签滚轮切换与自定义快捷键
6. [FluidVoice](https://github.com/altic-dev/FluidVoice): macOS 本地化实时语音转文字工具，默认离线 Parakeet 模型并可接入 OpenAI Groq
7. [MrRSS](https://github.com/WCY-dt/MrRSS): 跨平台桌面 RSS 阅读器，数据本地存储并支持智能订阅源发现翻译与摘要生成
8. [MyTube](https://github.com/franklioxygen/MyTube): 基于 yt-dlp 的私人视频库工具，支持 YouTube B 站等站点自动下载频道订阅与本地播放
9. [VibeTunnel](http://github.com/amantus-ai/vibetunnel): 零配置把浏览器变成 Mac 终端的安全隧道工具，支持密码保护多设备访问
