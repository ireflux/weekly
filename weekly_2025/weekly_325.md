# 实用工具

1. [Folder](https://github.com/bansal/folder): 开源的 Google Drive 替代方案，使用 Cloudflare D1 和 R2，支持 Google 和 GitHub 身份验证
2. [OpenAPK](https://github.com/mobilenetworkltd/openapk): 为 Android 用户提供开源应用和游戏列表，涵盖多种类别，附有源代码仓库链接和下载地址
3. [Subtitle Translator](https://github.com/rockbenben/subtitle-translator): 批量字幕翻译工具，支持多种字幕格式和翻译接口，可翻译成 35 种语言
4. [WeChatPadPro](https://github.com/luolin-ai/WeChatPadPro): 基于 WeChat Pad 协议的高级微信管理工具，支持多种微信功能
5. [InternetTest](https://github.com/Leo-Corporation/InternetTest): Windows 网络检测工具，支持多种网络功能
6. [StayFocused](https://github.com/daijinhai/StayFocused): 在线白噪音应用，提供多种自然白噪音
7. [Vibe Draw](https://github.com/martin226/vibe-draw): 手绘草图转 3D 建模工具，支持实时协作和导出
8. [Orpheus TTS](https://github.com/canopyai/Orpheus-TTS): 开源文本转语音系统，基于 Llama-3b 架构
9. [colors](https://github.com/lcpmgh/colors): 学术期刊配色推荐器，提供专业配色方案
10. [WeChatOCR](https://github.com/swigger/wechat-ocr): 为微信 OCR 功能提供跨语言调用接口的开源项目
