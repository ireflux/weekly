# 实用工具

1. [SingleFile](https://github.com/gildas-lormeau/SingleFile): 一款浏览器扩展，将完整网页保存为单个 HTML 文件，支持自动保存和批量操作
2. [WAuxiliary Plugins](https://hdshare.github.io/WAuxiliary_Plugin/): 基于 Xposed 的微信增强模块，提供消息防撤回、朋友圈增强等功能
3. [Quarkdown](https://github.com/iamgio/quarkdown): 一个扩展型 Markdown 排版系统，支持函数、变量和多种格式输出
4. [TaoSync](https://github.com/dr34m-cn/taosync): 一款基于 AList V3 的自动化同步工具，支持本地与网盘之间的文件同步和备份
5. [HuLa](https://github.com/HuLaSpark/HuLa): 一款跨平台即时通讯桌面应用，支持单聊、群聊和多种实用功能
6. [Operit AI](https://github.com/AAswordman/Operit): 一款 Android 开源 AI 智能助手，支持自然语言控制和高度可定制功能
7. [MediaNex](https://github.com/medianexapp): 一款插件化网盘视频播放器，支持多种网盘服务和媒体管理功能
8. [BitPlay](https://github.com/aculix/bitplay): 一个可以在线播放磁力视频的工具，支持磁力链接和 Torrent 文件
