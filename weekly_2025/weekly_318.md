# 实用工具

1. [Folder11](https://github.com/icon11-community/Folder11): 一个为 Windows 11 提供自定义目录图标的项目，包含 1122 个矢量图标，支持 SVG、AI 和 FIG 格式，适用于个性化设置和美化桌面
2. [PPTHide](https://github.com/du-yuxuan/PPTHide): 一款 Windows 小工具，帮助用户在演示时隐藏不必要的窗口，支持快捷键设置和托盘图标功能，提升演示流畅度
3. [TheBoringNotch](https://github.com/TheBoredTeam/boring.notch): 一款 macOS 软件，将 MacBook 屏幕顶部的刘海区域转变为多功能信息中心，支持音乐控制、日历提醒、摄像头预览等功能
4. [Ghosten-Player](https://github.com/GhostenEditor/Ghosten-Player): 一款开源视频播放器，支持云播放（阿里云盘、夸克网盘、Webdav）和本地播放，提供多线程加速、字幕支持、IPTV 直播等功能
5. [monolith](https://github.com/Y2Z/monolith): 一个命令行工具，可将网页打包成单个 HTML 文件
6. [Breeze](https://github.com/std-microblock/breeze-shell): 一款为 Windows 10/11 设计的右键菜单工具，提供全新交互动画，支持嵌入脚本扩展功能
7. [NeuraPress](https://github.com/tianyaxiang/neurapress): 一款专注于微信公众号排版的 Markdown 编辑器，支持实时预览、移动端适配、一键复制等功能
8. [MoePush](https://github.com/beilunyang/moepush): 基于 NextJS 和 Cloudflare 的消息推送服务，支持钉钉、企业微信、Telegram 等多种渠道，提供简单接口调用
9. [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus): 一款 B 站第三方客户端，支持多种手势操作、画质音质选项、弹幕字幕设置等功能，适用于 Android 和 iOS
10. [AdobeGenp](https://github.com/wangzhenjjcn/AdobeGenp): 一款针对 Adobe 系列软件的通用破解工具，支持 Adobe CC 2019 - 2025 多个版本，适用于 Windows 用户
