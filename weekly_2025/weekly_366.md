# 实用工具

1. [openclaw](https://github.com/openclaw/openclaw): 近日爆火的开源个人 AI 助理项目
2. [语燕拼音输入法](https://github.com/gurecn/YuyanIme): 基于 Rime 的安卓输入法，支持九键全拼双拼手写火星文及悬浮单手数字行模式
3. [Palmr](https://github.com/kyantech/Palmr): 自托管开源文件传输平台，支持 S3 兼容存储并无隐藏限制免费分享大文件
4. [GoRead](https://github.com/zhashut/goread): Android 轻量级本地电子书阅读器，支持 EPUB PDF Markdown HTML 及书架分组书签
5. [WindowsClear](https://github.com/tanaer/WindowsClear): Windows C 盘清理工具，一键迁移大文件夹并创建目录联接释放空间
6. [lsp-mcp](https://github.com/jonrad/lsp-mcp): 为 LLMs 提供语言服务器协议能力的 MCP 服务器，支持多语言动态生成 LSP 方法
7. [tmux-rs](https://github.com/richardscollin/tmux-rs): 用 Rust 重写的 tmux，兼容原生命令且性能更优
8. [Meowrch](https://github.com/meowrch/meowrch): 一键自动化安装与主题定制的 Arch Linux 桌面环境
9. [RustFS](https://github.com/rustfs/rustfs): 基于 Rust 的高性能分布式对象存储，兼容 S3 协议
