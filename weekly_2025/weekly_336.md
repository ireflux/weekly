# 实用工具

1. [JSON-Formatter](ireflux.github.io/JSON-Formatter/): 自动格式化 JSON 的网页版，还可以进行文本对比，开源无广告，方便日常开发使用
2. [Speedtest Tracker](https://github.com/alexjustesen/speedtest-tracker): 一款自我托管的应用程序，能够监控网络连接性能和在线时间
3. [NipaPlay-Reload](https://github.com/MCDFsteve/NipaPlay-Reload): 一款现代化的跨平台视频播放器，支持弹幕显示、多格式字幕和多音频轨道切换
4. [bilibili-comment-cleaning](https://github.com/Initsnow/bilibili-comment-cleaning): 一个 B 站评论清理工具，支持批量删除评论、弹幕和通知
5. [MicroBin](https://github.com/szabodanika/microbin): 一个轻量级自托管工具，集成了文本粘贴、文件分享和 URL 缩短等功能
6. [必应壁纸](https://github.com/niumoo/bing-wallpaper/): 一个提供微软 Bing 每日高清壁纸的网站
7. [NESBox](https://github.com/mantou132/nesbox): 一个 Web 多人 FC/NES 模拟器平台，支持在线联机对战
8. [Aria2Manager](https://github.com/Ftbom/Aria2Manager): 一款轻量高效且功能完善的 Aria2 管理客户端
9. [WeClone](https://github.com/xming521/WeClone): 用微信聊天记录和语音消息打造专属数字分身
10. [Anyquery](https://github.com/julien040/anyquery): 用 SQL 查询 GitHub、Notion 等 40 多个平台的数据
