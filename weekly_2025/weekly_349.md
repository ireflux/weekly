# 实用工具

1. [小鱼日历](https://github.com/syido/fish_calendar): Windows 桌面日历，支持自定义大小/背景、Outlook 日程同步，可嵌入 Wallpaper Engine
2. [Vicinae](https://github.com/vicinaehq/vicinae): Linux 高性能原生启动器，C++/Qt 构建，兼容 Raycast 扩展 API，支持 React+TS 插件开发
3. [Museeks](https://github.com/martpie/museeks): 跨平台本地音乐播放器，支持 MP3/FLAC/WAV/AAC，提供睡眠模式、播放速度调节与深色主题
4. [PicoShare](https://github.com/mtlynch/picoshare): 极简自托管文件分享服务，无大小/类型限制，提供直链下载，支持 Docker 与云端备份
5. [Lapce](https://github.com/lapce/lapce): Rust 编写的极速代码编辑器，内置 LSP、模态编辑、远程开发与插件系统。165 期的时候提到过，那时候还在开发阶段，现在已经可用了
6. [OCRmyPDF](https://github.com/ocrmypdf/OCRmyPDF): 为扫描版 PDF 添加可搜索/可复制 OCR 文本层，基于 Tesseract，支持命令行与批处理
7. [Input Source Pro](https://github.com/runjuu/InputSourcePro): macOS 自动输入法切换工具，根据应用/网站场景智能切换输入源
8. [Nexus Terminal](https://github.com/Heavrnl/nexus-terminal): 现代化 Web SSH/RDP 客户端，内置多标签、SFTP、Docker 面板与 2FA/验证码支持
9. [MAZANOKE](https://github.com/civilblur/mazanoke): 开源浏览器端图片优化工具，支持压缩、格式转换与批量处理，可离线运行或 Docker 部署
10. [geekgeekrun](https://github.com/geekgeekrun/geekgeekrun): 开源求职自动化工具，支持 Boss 直聘海投、自动开聊、已读提醒与僵尸职位清理，跨平台支持
11. [Caido](https://github.com/caido/caido): 面向安全研究者的高效 Web 应用审计工具，月更版本、Roadmap 公开、社区活跃
