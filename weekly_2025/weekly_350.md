# 实用工具

1. [ComeCut](https://github.com/juntaosun/ComeCut): 多平台本地视频编辑器，支持 AI 字幕翻译（SRT/VTT/LRC）与云端零上传，在线即可用
2. [Cmbok](https://github.com/hlning/cmbok): Windows 开源漫画/电子书下载器，支持多线程、EPUB 转换与 Kindle 兼容管理
3. [Local Dream](https://github.com/xororz/local-dream): Android 本地 Stable Diffusion 应用，支持 Snapdragon NPU 硬件加速、NSFW 过滤与自定义模型导入
4. [DTV](https://github.com/chen-zeong/dtv): 跨平台斗鱼+抖音直播客户端，基于 Tauri 2.0，集成弹幕、收藏与主题切换
5. [Ceru Music](https://github.com/timeshiftsauce/CeruMusic): 跨平台插件化音乐播放器，不内置音源，用户可自由安装插件获取歌曲/歌词/封面
6. [mimotion](https://github.com/TonyJiangWJ/mimotion): GitHub Actions 自动脚本，定时向小米运动上传自定义步数，支持多账户与推送通知
7. [FlyCut Caption](https://github.com/x007xyz/flycut-caption): 浏览器端 Whisper 字幕生成组件，支持语音识别、时间轴编辑与 SRT/JSON/硬字幕导出，完全本地运行
8. [microsandbox](https://github.com/microsandbox/microsandbox): 微虚拟机隔离沙箱，<200 ms 启动，为 AI 或不信任代码提供安全执行环境
